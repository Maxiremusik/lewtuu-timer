***Lewtuu Timer***

Die offizielle Timer-Mod von Streamer Lewtuu, von ihm selbst genutzt.
Zeigt deine Spielzeit mit einem Weiß-Lila-Fade in der Action-Bar an.

***Installation***

Minecraft Java ab 26.1, Fabric Loader ab 0.19.3 und die zur Minecraft-Version passende Fabric API werden benötigt. Kopiere lewtuu-timer.jar in deinen mods-Ordner.

Die Mod läuft nur auf deinem Client und benötigt keine OP-Rechte.
Sie wird gegen 26.1 gebaut. Neuere Versionen dürfen sie laden, sind aber nicht automatisch getestet.

***Befehle***

**/timer start** startet einen neuen Timer. Bei einem vorhandenen Timer bestätigst du das Überschreiben durch erneute Eingabe innerhalb von zehn Sekunden.
**/timer pause** pausiert den Timer und zeigt „Pausiert“ an.
**/timer resume** setzt den Timer fort.
**/timer stop** löscht den Timer und blendet ihn aus.

Alle Befehle funktionieren auch mit /lewtuutimer.
Timerstände werden pro Server in config/lewtuutimer.json gespeichert und beim nächsten Join pausiert geladen.

***Selbst bauen***

Java 25 oder neuer installieren, dann ./gradlew build ausführen.
Unter Windows: gradlew.bat build.
Die fertige Datei liegt unter build/libs/lewtuu-timer.jar.
